The agent / one compliant fix per exception

Plan. Prove. Route.

Ready to approve→Waiting on employee→Needs judgment
  • Whitelisted resolutions: remove a duplicate, fill a punch, pay a missed-meal premium (never move punches), send schedule clashes to a manager.
  • AI reads the note only where it changes the answer: the real clock time, or worked vs sick.
  • Every fix is applied in memory and the pay engine recomputes the whole period first.
  • Employees confirm changes to their hours in one tap; next-week overtime is prevented with engine-priced swaps.

Harness / the model cannot invent or decide

Every AI claim is checked
against the note and the engine.

Note reading (strict JSON)→Quote + time grounded in code→Engine simulation
  • A stated time is accepted only if a sentence in the note contains it; one retry with the exact error, then rules fallback.
  • Notes that try to instruct the system never reach the model.
  • The agent can author but never approve; approval re-verifies and commits atomically.
  • Open-weight model (qwen3:1.7b, Apache-2.0) running locally; AI off by default; hash-chained audit.
